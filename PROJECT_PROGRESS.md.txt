# Private PDF AI Assistant

## Project Overview

A secure AI-powered document assistant that allows users to:

* Register and login
* Upload confidential PDFs
* Process PDFs locally
* Store embeddings locally
* Chat with uploaded documents using local AI models (Ollama)
* No external AI APIs

---
